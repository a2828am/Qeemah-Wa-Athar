
Database Connection Configuration

1. نظرة عامة

يُستخدم هذا الملف لإنشاء وإدارة الاتصال بقاعدة بيانات MySQL باستخدام PHP وامتداد MySQLi، وتوفير اتصال موحد يمكن استخدامه من مختلف أجزاء المشروع.

2. اسم الملف

"connection.php"

3. المسار

"database/config/connection.php"

4. الوظائف الرئيسية

- قراءة إعدادات الاتصال من متغيرات البيئة (Environment Variables).
- تحديد بيانات خادم قاعدة البيانات.
- إنشاء اتصال باستخدام MySQLi.
- التحقق من نجاح الاتصال ومعالجة أخطاء الاتصال.
- ضبط ترميز الاتصال باستخدام "utf8mb4" لدعم اللغة العربية والرموز التعبيرية.

5. البارامترات (Parameters)

البارامتر| الوصف| القيمة الافتراضية
"DB_HOST"| عنوان خادم قاعدة البيانات| "127.0.0.1"
"DB_PORT"| منفذ الاتصال| "3306"
"DB_DATABASE"| اسم قاعدة البيانات| "social_platform_database"
"DB_USERNAME"| اسم المستخدم| "root"
"DB_PASSWORD"| كلمة المرور| فارغة

6. بارامترات إنشاء الاتصال

يستخدم الملف الدالة "new mysqli()" وتستقبل:

البارامتر| الوظيفة
Host| عنوان الخادم
Username| اسم المستخدم
Password| كلمة المرور
Database| اسم قاعدة البيانات
Port| منفذ الاتصال

7. معالجة الأخطاء

يتحقق الملف من حالة الاتصال باستخدام "connect_errno"، وفي حالة فشل الاتصال:

- تعيين رمز استجابة HTTP إلى "500".
- إيقاف تنفيذ البرنامج.
- إظهار رسالة توضح فشل الاتصال.

8. ترميز البيانات

يستخدم الملف:

"utf8mb4"

لضمان دعم اللغة العربية ومختلف الرموز والمحارف.

9. تعليمات الاستخدام

- يجب ضبط بيانات الاتصال قبل تشغيل المشروع.
- يُفضّل استخدام ملف ".env" لحفظ بيانات الاتصال.
- يمنع رفع كلمات المرور الحقيقية إلى مستودع GitHub.
- يجب استخدام هذا الملف كمصدر موحد لإنشاء الاتصال بقاعدة البيانات بدلاً من تكرار كود الاتصال في الملفات الأخرى.

10. ملاحظات التطوير

- عدم إظهار تفاصيل أخطاء قاعدة البيانات في بيئة الإنتاج.
- تسجيل الأخطاء في سجلات النظام (Logs).
- التأكد من نجاح ضبط الترميز.
- تجنب فتح اتصالات متعددة دون حاجة.
  وظيفة الملف: إنشاء الاتصال بقاعدة بيانات MySQL وإعداد الاتصال لاستخدامه في بقية ملفات المشروع.
